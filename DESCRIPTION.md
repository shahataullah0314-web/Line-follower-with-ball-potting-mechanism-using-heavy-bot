Arduino Line Follower Robot with Ultrasonic & ESP32 Detection is a compact robotics project built for smooth line tracking and fast obstacle response. The system combines five IR sensors for line detection, a PID controller for stable movement, three servos for object collection, and dual triggers from an HC-SR04 ultrasonic sensor plus an ESP32 module. It is designed to stop and handle each confirmed obstacle, open the next servo, then resume following a black track without halting permanently. The robot tracks the path using weighted sensor values and corrects motor speed dynamically. During normal operation, it stays on the line with a base drive speed and uses pivot turns when the path is lost. When the ultrasonic sensor detects a target within a calibration threshold of fifteen centimeters, the controller confirms the reading with a short debounce process before acting. Similarly, the ESP32 input can signal detected balls from an external module. Each valid detection increments a counter and opens the matching servo in sequence. After the third collection, the robot keeps following the line while a timed closing sequence returns the servos to rest one by one. The code uses nonblocking state management with millis() timers, so servo activation and closing delays do not freeze the main loop. This makes the design safer and more responsive than blocking delay-based implementations. The architecture delivers a reliable experience for competition and educational use, with clear serial logging for debugging. The project is ready to run on common Arduino platforms, and it includes a recommended PlatformIO setup for easy building and uploading. Pin assignments are straightforward, and the software supports common motor driver wiring. It supports Arduino Uno or Nano, uses common servo power rails, and provides clear guidance for wiring, PID tuning, and calibration in a single package with simplicity. This description targets hobbyists and robotics students who want a practical example of PID line following integrated with object collection and ultrasonic awareness. It emphasizes maintainability, modular detection logic, and a real-world flow where the robot acts immediately on obstacle confirmation, collects the object, then continues its mission along the track.
